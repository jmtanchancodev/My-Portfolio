# My Portfolio

Welcome to my personal portfolio website
This project showcases my skills, projects, and background as a **Frontend Developer** with experience in **web development, UI design, and quality assurance**.

🔗 **Live Website:**  
https://jmtanchancodev.github.io/My-Portfolio/

---

##  About the Project

This portfolio is a fully responsive, single-page website built to present:
- My professional background and education
- Technical skills and proficiency levels
- Personal projects with detailed previews
- Contact information and external profiles

The design focuses on **clarity, responsiveness, and clean UI**, while maintaining performance and accessibility best practices.

---

## 🛠️ Built With

- **HTML5** – Semantic structure
- **CSS3** – Custom styling and responsive layouts
- **JavaScript (ES6)** – Interactivity and DOM manipulation
- **ScrollReveal.js** – Smooth scroll-based animations
- **Git & GitHub** – Version control and deployment
- **GitHub Pages** – Live hosting

---

## 🎯 Features

- Fully responsive design (desktop, tablet, mobile)
- Animated sections using ScrollReveal
- Interactive project gallery with modal previews
- Clean navigation with active section highlighting
- Optimized images using WebP format
- Deployed and maintained via GitHub Pages
